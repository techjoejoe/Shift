🗺️ How to Find Card Game Data in GA4
  1. 1
    Go to Reports → Engagement → Events in GA4. You'll see card_drawn, new_round, and reset_all listed with event counts.
  2. 2
    To see only card game page visitors, go to Reports → Engagement → Pages and screens, then filter by page title = SHIFT Card Game.
  3. 3
    Click any event name to drill in and see which SHIFT phase or scenario is drawn most — the custom parameters are in the event details.
  4. 4
    For a single live view, create a free Looker Studio report, connect it to this GA4 property, and paste the share URL in the embed box above.
